# 八牌 P2P β v0.9.0（独立試作）

従来版のGitHub/Render/Vercelは変更しないでください。別リポジトリにこのZIPの中身をアップロードし、別Vercelプロジェクトで公開します。

## 接続
1. 親機で multiplayer.html →「部屋を作る」→接続コードをコピーして相手へ送る。
2. 子機で multiplayer.html →「参加する」→親機の接続コードを貼り付けて「読み込む」。
3. 子機に表示された返答コードを親機へ返送。
4. 親機が返答コードを貼り付け「読み込む」。接続後は対局画面に切り替わります。

音声は接続後、双方が手動でマイクONします。

## 制約
* WebRTCは同じWi-Fiなら比較的つながりやすいですが、異なる回線や厳しいNAT環境ではTURN中継なしに接続できないことがあります。
* この試作にはTURNサーバーは含まれません。
* 端末のいずれかが終了すると対局は終了します。再接続は未実装です。
* 親機が山牌・相手の牌を保持するため、親機を完全に信頼する前提です。競技大会等の不正対策には不十分です。
* この試作はコードを手動交換する方式です。従来の6桁の部屋番号だけでは接続できません。
* 実機で2台同時接続のテストは未実施です。


## v0.9.1 QR接続
部屋を作って接続コードが出たらQRを表示できます。スマホで「QRコードを読み取る」を押し、PC側のQRを順番に読み取ります。返答コードはスマホ側のQRをPCカメラで読み込むか、従来のコピー＆ペーストで返してください。ブラウザにBarcodeDetectorがない場合は従来方式をご利用ください。QR生成は付属のMITライセンスQRライブラリでオフライン動作します。ゲーム本体・Render版は変更していません。
